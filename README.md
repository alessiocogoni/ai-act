# AIO ACT

MVP gestionale per il monitoraggio della compliance AI Act.

## Avvio
Aprire `index.html` in un browser moderno oppure servire la directory con `python -m http.server 8000` e visitare http://localhost:8000.

## Pubblicazione
In GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Funzioni
Dashboard, registro sistemi AI, CRUD attività e scadenze, screening preliminare, ricerca, esportazione JSON, copilota contestuale a regole, layout responsive.

## Limiti
Dati locali al browser, nessuna autenticazione o sincronizzazione, nessun backend o modello generativo. Non inserire dati sensibili. Lo screening non costituisce consulenza legale né certificazione di conformità.
